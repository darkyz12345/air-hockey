Жанр: Casual Arcade / Sports
Концепция: Классический аэрохоккей против AI с системой уровней
Главная Особенность: На последующих уровнях на игровом поле появляются препятствия, которые изменяют траекторию шайбы и усложняют игру

Игровой цикл:
```
Главное меню
      ↓
Выбор уровня
      ↓
Матч
      ↓
Победа ─────→ Следующий уровень
      │
      ↓
Поражение
      ↓
Повторить
```
Управление:
ПК: Mouse -> Player Paddle
Телефон: Touch -> Player Paddle

Физика:
Puck: RigidBody2D, Collider2D
Paddle: RigidBody2D, Collider2D
Wall: Collider2D
Goal
Obstacle: Collider2D

Шайба не должна терять скорость после каждого столкновения настолько, чтобы постепенно остановиться
