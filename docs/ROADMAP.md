# Development Roadmap

## Overview

Air Hockey is developed in short, focused sprints.

The primary objective is to reach a playable and publishable version quickly, then use real player feedback and metrics to determine whether further development is justified.

# Post-Release

After publication, development decisions will be based on actual player data.

Potential areas for iteration:

* retention;
* session duration;
* level completion;
* difficulty balance;
* player feedback;
* technical performance;
* monetization.

New features should be prioritized according to their expected impact rather than added solely because they are interesting.

---

# Long-Term Possibilities

If the initial version demonstrates sufficient player interest, potential future features include:

* additional arenas;
* additional obstacle types;
* power-ups;
* skins;
* achievements;
* leaderboards;
* advanced AI;
* special game modes;
* multiplayer.

These features are intentionally deferred until the core game has been validated.
