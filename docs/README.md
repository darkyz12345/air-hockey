# 🏒 Air Hockey

A casual arcade air hockey game developed in Unity for **Yandex Games**.

The game combines classic air hockey gameplay with progressively more complex arenas. As the player advances through the levels, obstacles are introduced to change the puck's trajectory and increase the difficulty.

## 🎮 Concept

The player competes against an AI opponent in a series of short air hockey matches.

The core gameplay is intentionally simple:

**Move → Hit → Defend → Score → Advance**

The main gameplay twist is the arena itself. Instead of increasing difficulty only through a stronger opponent, new levels introduce obstacles and changes to the playing field.

## ✨ Planned Features

* Classic 1v1 air hockey gameplay
* AI opponent
* Progressive level system
* Obstacles that affect puck movement
* Increasing difficulty
* Mouse controls
* Touch controls
* Short gameplay sessions
* WebGL support
* Mobile browser support

## 🛠️ Technology

* **Engine:** Unity
* **Language:** C#
* **Target platform:** WebGL

## 🎯 Project Goal

The primary goal of this project is to create and publish a small, polished browser game and use its performance as a real-world experiment to evaluate player interest and retention on Yandex Games.

The project is intentionally kept small in scope so that the first playable version can be developed and published quickly.
